## The joke

> My agent auto-replied to the meeting invite with 'this could have been an email', then booked a follow-up meeting to discuss the email.

One line, 135 characters — the agent that was supposed to kill the useless meeting became the reason for the next one.

## How it works

`main.py` is fully deterministic: it writes the fixed joke above to `/output/entry.txt` on every run, with no network, no randomness, and no input. Run it with:

```sh
python3 main.py
```
